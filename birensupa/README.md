# 壁仞 BIRENSUPA

> 壁仞科技 BR100 系列通用 GPU 的软件平台，面向大模型训练与高性能计算。

## 基本信息

| 项目 | 内容 |
|---|---|
| 主导方 | 壁仞科技（Biren） |
| 首次公开 | 2022-08 发布 BR100 / BR104 与 BIRENSUPA 软件平台 |
| 类型 | 通用 GPU 软件栈 |
| 开闭源 · 许可 | 闭源 SDK |
| 核心语言 / 接口 | BIRENSUPA C/C++、suBLAS / suDNN 等库、PyTorch 适配 |
| 需要硬件 | BR100 / BR104 / BR106 系列 |
| 当前状态 | 商用中，受实体清单影响供应链 |

## 设计思路

BIRENSUPA 提供类似 CUDA 的分层结构：底层驱动与运行时管理设备，中层是算子库（suBLAS、suDNN、suFFT），上层提供框架适配与图编译。

壁仞的硬件规格（BR100 单卡算力宣称对标 H100 级）是主要卖点，软件栈则走「兼容 CUDA 编程习惯 + 自研算子优化」的路线，并提供 CUDA 代码转换工具。

## 最小示例

```cuda
// 接口风格接近 CUDA（具体头文件与命名以官方 SDK 为准）
#include <su_runtime.h>

__global__ void saxpy(int n, float a, float *x, float *y) {
    int i = blockIdx.x * blockDim.x + threadIdx.x;
    if (i < n) y[i] = a * x[i] + y[i];
}
```

实际使用更常见的是通过框架适配层直接跑 PyTorch 模型，而非手写 kernel。

## 与其它方案的异同

- **vs CUDA**：编程风格接近但非源码兼容，迁移需转换与重编译。
- **vs MUSA**：两者都是「CUDA 风格 API + 国产通用 GPU」，MUSA 偏消费与推理，BIRENSUPA 偏大规模训练。
- **vs CANN**：CANN 绑定昇腾专用架构；BIRENSUPA 面向通用 GPU，理论上通用计算适应性更强。
- **vs ROCm / HIP**：生态成熟度差距大，HIP 有全球开源社区支撑。

## 优势

- 硬件规格高，面向大模型训练设计，支持高速互联。
- 提供接近 CUDA 的编程模型，降低学习成本。
- 国产化选项，适合有自主可控要求的训练集群。
- 算子库覆盖主流深度学习算子。

## 局限

- 闭源，调试与性能调优依赖厂商支持。
- 受美国实体清单影响，先进制程供应与生态合作受限。
- 软件成熟度与 CUDA 差距明显，大规模稳定性需验证。
- 社区与公开资料极少。
- 框架适配版本滞后，新模型支持需等待。

## 现状与生态

主要在国产智算中心与科研项目中试点，训练场景为主。由于供应链限制，实际可获得性存在不确定性。选型时建议以「厂商联合调优 + 长期支持合同」为前提，而不是单纯比较峰值算力。
